# 順位表と成績分布のしくみ（作り方）

点数は次の2つの形で使います。

| | 誰が見られるか | 中身 |
|---|---|---|
| ① 順位表 | 学校アカウント（gl.pen-kanagawa.ed.jp）でログインした人だけ | 掲載に同意した人のニックネームと点数・順位 |
| ② 成績分布 | 誰でも（ポータルの「成績」ページ） | 平均・標準偏差・10点刻みの人数だけ。個人の行は載せない |

出席番号は二重回答を防ぐためだけに使い、①にも②にも載せません。

---

## 1. Googleフォームを作る（学校アカウントで）

1. 学校アカウントで Google フォームを新規作成する。題名の例：「2026年度 後期中間 点数提供フォーム（湘南 104回生）」
2. **設定**を次のようにする。
   - 「回答」→「**回答を〔学校の組織〕と信頼できる組織のユーザーに制限する**」をオン
   - 「メールアドレスを収集する」→「確認済み」
   - 「回答を 1 回に制限する」をオン
   - 「送信後に回答を編集」をオン（あとから点数を直せるように）
3. **質問**を次の順で作る（列の位置がずれないよう、順番どおりに作ってください）。

| # | 質問 | 形式 | 必須 | 補足 |
|---|---|---|---|---|
| 1 | ニックネーム | 記述式 | ○ | 順位表に載る名前。本名や出席番号は使わないよう説明文に書く |
| 2 | 出席番号（4桁） | 記述式 | ○ | 回答の検証：正規表現「一致する」`^\d{4}$` |
| 3 | 試験 | プルダウン | ○ | 「2026年度 後期中間」（試験ごとにフォームをコピーして選択肢を変える） |
| 4〜14 | 現代の国語／言語文化／数学Ⅰ／数学A／化学基礎／生物基礎／ECⅠ／論表Ⅰ／地理総合／公共／情報Ⅰ | 記述式 | × | 回答の検証：数値「範囲内」0〜100。受けていない・言いたくない科目は空欄でよい |
| 15 | 順位表への掲載 | ラジオボタン | ○ | 「ニックネームで載せる」／「載せない（分布の集計だけに使う）」 |
| 16 | 同意 | チェックボックス | ○ | 「入力した点数が、個人が分からない形で集計・公開されることに同意します」 |

> 質問のタイトルは、表の文字と**一字一句同じ**にしてください（集計スクリプトが列名で読み取ります）。

4. 「回答」タブ →「スプレッドシートにリンク」で、回答用スプレッドシートを作る。
   - 列は A タイムスタンプ／B メールアドレス／C ニックネーム／D 出席番号（4桁）／E 試験／F〜P 11科目／Q 順位表への掲載／R 同意 になります。
5. 回答用スプレッドシートは**誰とも共有しない**（メールアドレスと出席番号が入っているため）。
6. 回答シートの S1 に「合計」と入れ、S2 に次の式を入れる（11科目すべてに点数がある人だけ合計を出す）。

```
=ARRAYFORMULA(IF(C2:C="","",IF(MMULT(--(F2:P<>""),SEQUENCE(11,1,1,0))<11,"",MMULT(IFERROR(F2:P*1,0),SEQUENCE(11,1,1,0)))))
```

## 2. 順位表を作る（別のスプレッドシート）

回答シートそのものを共有すると出席番号やメールアドレスまで見えてしまうので、**別のスプレッドシート**に必要な列だけを取り込みます。

1. 学校アカウントで新しいスプレッドシート「後期中間 順位表（104回生）」を作る。
2. B1 に次の式を入れる（`回答シートのURL` は手順1-4のスプレッドシートのURLに置き換える）。初回は「アクセスを許可」を押す。

```
=QUERY(IMPORTRANGE("回答シートのURL","フォームの回答 1!C:S"),"select Col1, Col17, Col4, Col5, Col6, Col7, Col8, Col9, Col10, Col11, Col12, Col13, Col14 where Col15 = 'ニックネームで載せる' and Col17 is not null order by Col17 desc label Col1 'ニックネーム', Col17 '合計'",1)
```

3. A1 に「順位」、A2 に次の式を入れる（同点は同じ順位）。

```
=ARRAYFORMULA(IF(B2:B="","",RANK(C2:C,C2:C,FALSE)))
```

4. 「共有」→「一般的なアクセス」を「**〔学校の組織〕**（リンクを知っている組織内のユーザー）・閲覧者」にする。
5. このスプレッドシートのURLを、ポータルの `data/config.json` の `rankSheetUrl` に、フォームのURLを `formUrl` に書く（Claude に送ってくれれば反映します）。

## 3. 成績分布（ポータルで公開）を更新する

1. 回答用スプレッドシートを「ファイル → ダウンロード → カンマ区切り形式（.csv）」で保存する。
2. 次のどちらかで `data/stats.json` を作り直す。
   - Claude に CSV を渡して「成績分布を更新して」と頼む
   - 自分で `python3 tools/make_stats.py 回答.csv > data/stats.json` を実行して push する
3. `stats.json` に入るのは科目ごとの人数・平均・標準偏差・10点刻みの人数だけです。回答が10人未満の科目は出力されません（`config.json` の `minN` で変更可）。

## 注意

- **CSV（回答そのもの）はリポジトリに入れないでください。** このリポジトリは公開されています。
- 協力をお願いするときは、「何に使うか」「誰が見られるか」「いつでも削除を頼めること」を伝えてください。削除を頼まれたら、回答シートからその人の行を消し、成績分布を作り直します。
